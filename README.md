CodeAlpha Tasks

This repository contains the projects completed as part of the CodeAlpha Internship Program.

Projects Included

1. AI Language Translation Tool

A beginner-friendly AI Language Translation Tool developed using Python and Streamlit. The application translates text from one language to another using Google Translator API and also includes text-to-speech functionality.

Technologies Used:

- Python
- Streamlit
- Google Translator API
- gTTS

2. FAQ Chatbot

An AI-powered FAQ Chatbot developed using Python and Natural Language Processing (NLP). The chatbot answers user queries based on predefined frequently asked questions and provides quick responses through an interactive interface.

Technologies Used:

- Python
- Streamlit
- NLP
- NLTK
