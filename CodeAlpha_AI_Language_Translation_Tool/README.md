AI Language Translation Tool

Overview

AI Language Translation Tool is a beginner-friendly Python project developed using Streamlit.
The application allows users to translate text from one language to another using Google Translator API integration.

The project also includes text-to-speech functionality, enabling users to listen to the translated output.



Features

- User-friendly interface
- Translate text between multiple languages
- Text-to-speech audio support
- Copy translated text option
- Professional lavender and pink themed UI
- Beginner-friendly implementation
- No separate backend required



Technologies Used

- Python
- Streamlit
- deep-translator
- gTTS (Google Text-to-Speech)



Installation

Install the required libraries using:

pip install streamlit deep-translator gtts



Running the Project

Run the application using:

python -m streamlit run app.py

How It Works

1. Enter text into the input box.
2. Select source language.
3. Select target language.
4. Click the Translate button.
5. View translated text.
6. Listen to translated audio output.
