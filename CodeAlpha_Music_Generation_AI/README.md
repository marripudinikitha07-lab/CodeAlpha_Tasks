AI Music Generation System

Overview

The AI Music Generation System is a beginner-friendly Python project that automatically generates musical note sequences and converts them into MIDI files. The application provides a simple Streamlit-based user interface where users can generate and download AI-created music.

Features

- Generate unique music sequences automatically
- Create MIDI files from generated notes
- Download generated music files
- Simple and interactive Streamlit interface
- Lightweight and easy to use

Technologies Used

- Python
- Streamlit
- Music21

Project Structure

CodeAlpha_Music_Generation_AI

├── app.py

├── requirements.txt

├── README.md

└── generated_music.mid

Installation

Install the required libraries:

pip install -r requirements.txt

Running the Project

Run the Streamlit application:

streamlit run app.py

Usage

1. Open the application in your browser.
2. Click the "Generate Music" button.
3. A new MIDI music file will be created.
4. Download and play the generated music.

Output

The generated music is saved as:

generated_music.mid
